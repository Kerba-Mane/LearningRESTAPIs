# LearningRESTAPIs

A Spring Boot project demonstrating **CRUD operations** (Create, Read, Update, Delete) for managing students via RESTful APIs.

---

## Technologies Used

- **Java 17**  
- **Spring Boot**  
- **Spring Data JPA**  
- **Maven**  
- **MySQL**  
- **IntelliJ IDEA**  

---

## 🚀 Features

- Add a new student  
- Fetch student details  
- Update existing student  
- Delete student  
- RESTful API endpoints following best practices
